---

# 📌 Overview

Home Sphere is a smart home automation application designed to simplify the management of household devices through a modern mobile interface.

The application communicates with Arduino-powered hardware using Firebase Realtime Database, allowing users to monitor appliance status and remotely control connected devices with minimal latency.

The project demonstrates Flutter application architecture, Firebase integration, hardware communication, authentication, and responsive mobile UI design.

---

# 🎯 Why I Built This

The goal of Home Sphere was to explore the integration between mobile applications and embedded hardware while building a complete IoT ecosystem.

During development I focused on:

- Mobile-to-hardware communication
- Firebase Realtime Database
- Authentication
- Responsive Flutter UI
- Device synchronization
- Secure smart home management

Some key engineering decisions include:

- Firebase Realtime Database for low-latency synchronization.
- Modular Flutter widgets for reusable UI.
- Separation between presentation and business logic.
- Cloud-based device state management.

# 🚀 Getting Started

## Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio
- Firebase Project
- Arduino Board

---

## Installation

Clone the repository

```bash
git clone https://github.com/MohamedZakaria9014/Home-Sphere-Mobile-Application.git
```

Navigate into the project

```bash
cd Home-Sphere-Mobile-Application
```

Install packages

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
